Arquitectura del Sistema

Cómo funciona la plataforma

Desde datos abiertos de SUTRAN hasta visualizaciones interactivas.
01

Datos abiertos

Se toma el CSV oficial de SUTRAN publicado en datosabiertos.gob.pe.

02

Limpieza

Python normaliza fechas, separador CSV, departamento, modalidad y valores numéricos.

03

API REST

El backend expone resumen, filtros, registros, series y heatmap temporal.

04

Frontend

JavaScript consume la API y actualiza KPIs, mapa, gráficos y tabla sin recargar.

05

Análisis

La plataforma ayuda a detectar zonas y patrones de mayor incidencia vial.

Tecnología

Tecnologías que potencian la plataforma

Arquitectura tecnológica de la plataforma, diseñada para operar en entornos web y desplegarse de forma segura y escalable en servicios de nube.
Backend

Python 3

Servidor HTTP local, API REST, lectura CSV, limpieza de datos y cálculo de indicadores.

Frontend

HTML5 · CSS3 · JavaScript

Interfaz web interactiva con filtros, estados visuales y consumo de API mediante `fetch`.

Visualización

Leaflet · Chart.js

Mapa departamental del Perú, gráficos mensuales, ranking y distribución por modalidad.

Datos

datosabiertos.gob.pe

CSV oficial de SUTRAN/MTC con fecha, hora, departamento, vía, kilómetro y consecuencias.

Calidad

Validación y logging

Separación por capas, parámetros controlados, manejo de errores y trazabilidad básica.

Nube

Despliegue futuro
